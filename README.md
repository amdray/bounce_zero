# Bounce Zero

Порт оригинальной игры **Bounce (2002, Java/Sun для Nokia 7210)** на платформу **PlayStation Portable (PSP)**.  
Игровая логика полностью переписана на **C**, при этом используются только оригинальные игровые ассеты из версии для телефонов Nokia.  
Проект создан в исследовательских целях, без модификации контента.

## Особенности
- Полная переимплементация игрового цикла и физики
- Чтение и использование оригинальных игровых данных из JAR-версии Bounce 2002:
    - файлы уровней 001-011: реализован парсер формата J2ME-уровней, с предзагрузкой/кэшированием
    - текстуры PNG: собственный загрузчик на `stb_image` с размещением текстур в VRAM
    - файлы звуков OTT: реализован парсер RTTTL/OTT и генерация PCM в реальном времени
    - `lang`-файлы: реализован парсер локализации с выбором языка по системному языку PSP (с fallback на `lang.xx`)
    - шрифты Nokia 7210 (9, 12, 16, 23, 24): извлечены из FONT.xml и упакованы в бинарный формат CBMF (T4-nibble); рендеринг через GU_PSM_T4 + CLUT на PSP GU
    - возможность выбрать уровень (1-11)
    - система сейвов через Sony PSP Savedata Utility (`DATA.BIN`, `SCE_UTILITY_SAVEDATA_*`)
- Совместимость с реальным устройством PSP и эмулятором PPSSPP

## Недостатки, недоработки
- таймер физики в оригинале 33 кадра, в этом порте - 30 кадров - **исправлено в 1.1**
- шрифт рендерился попиксельно без аппаратного ускорения - **исправлено в 1.2** (переход на CBMF + PSP GU T4/CLUT)
- мимнимальные расхождения физики, не влияющие на геймплей, будт поправлены в новой версии - **исправлено в 1.1**

## Чит-коды
- Во время игры: `L + R` (нажать `L`, удерживая `R`) - переключает режим бессмертия.
- Эффект: мяч не лопается от опасностей (в `pop_ball()` срабатывает ранний `return`).
- При переключении проигрывается звуковой сигнал.

## Сборка
Необходим [PSP SDK (pspdev)](https://github.com/pspdev/pspdev). После установки:

```bash
make
```

Собранный файл `EBOOT.PBP` появится в каталоге `release/`.

## Запуск
Скопируйте содержимое папки `release/` на карту памяти PSP:

```
/PSP/GAME/BounceZero/
```

или откройте `EBOOT.PBP` через эмулятор PPSSPP.

## Совместимость
- PlayStation Portable 6.00 и выше
- Эмулятор PPSSPP
